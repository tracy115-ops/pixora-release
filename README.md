## 💡 为什么选择 Pixora？(Why Pixora?)

日常办公与开发中，你是否也经常经历这种**割裂而繁琐**的操作链路：
* ❌ 遇到报错弹窗，截图后保存，再打开浏览器丢给 ChatGPT 提问；
* ❌ 看到外文文献或设计图，截图后打开翻译软件手动上传；
* ❌ 想要图片中的代码或表格文字，还得单独开一个 OCR 识别软件；
* ❌ 钉在桌面的参考图总是挡住鼠标，写代码时只能频繁移开或关掉；
* ❌ 想要给客户或同事写教程，画框、标数字、打马赛克手忙脚乱……

> 🎯 **Pixora 为终结这些低效痛点而生！**  
> 它将 **极致纯粹的毫秒级桌面截图** 与 **大模型 AI 视觉能力** 深度融合。  
> 选区一框，**OCR、翻译、AI 多轮对话、自动标注、鼠标穿透贴图** 全部在当前屏幕一键完成，彻底重塑你的桌面生产力！

## 🔥 核心功能亮点详解 (Features)

### 🤖 1. AI 视觉大脑：截图瞬间化身智能助手
* **多模态图文无缝对话**：
  * 截取任何报错日志、架构图、原型稿，点击右下角 **AI 助手** 即可直接发起对话。
  * 轻松提问：“*这段报错什么原因？如何修复？*”、“*根据这个 UI 设计生成 Tailwind 代码*”、“*分析并总结这张财报的关键指标*”。
  * 界面支持打字机流式输出，更配备 **随时停止 (⏹)** 按钮，长回复随心掌控。
* **一键 AI 截图翻译**：
  * 无论是海外技术文档、论文图表还是外文社交媒体，框选后一键点击翻译，直接展示双语对照，告别繁琐复制。
* **高精度 AI OCR 文本提取**：
  * 自动剔除噪点，精准提取截图中代码、排版文本与公式，一键完整复制。
* **AI 智能 UI 自动标注**：
  * 大模型自主理解界面结构，自动识别按钮、输入框、导航栏并框选高亮，产品分析与竞品复盘效率倍增。
* **自由配置大模型服务商**：
  * 支持无缝接入 **OpenAI (GPT-4o)**、**Anthropic (Claude 3.5 Sonnet)** 以及本地离线模型 **Ollama**，数据私密更自由。

---

### 📌 2. 贴图工作台 (Pin)：参考临摹与对比利器
将有价值的画面一键“钉”在桌面上，作为持续参考的便签窗口：
* **鼠标穿透模式 (`F9`) —— 照着写代码与画图的神器**：
  * 开启后贴图悬浮置顶，但鼠标点击、滚动完全**穿透至下层窗口**！你可以边对照设计图边写前端页面，无需反复切屏或分屏。
* **一键黑白灰度 (`5`) & 颜色反转 (`I`)**：
  * 按 **`5`** 切换为黑白灰度：去除色彩干扰，专注于界面排版比例、明暗对比与文字灰阶。
  * 按 **`I`** 切换为夜间反色：将刺眼的白底文档/图表反转为黑色背景，夜间工作护眼不疲劳。
* **自由图像变换**：
  * 滚轮平滑缩放 (10% ~ 500%)，按 `R` 旋转 90 度，按 `F` / `Shift+F` 水平或垂直翻转。
* **剪贴板双模式超强复制**：
  * 截图复制后，不仅能在微信/Word 中粘贴为图片，在 **Windows 文件资源管理器或桌面上直接按 `Ctrl + V`，立刻粘贴出 `.png` 图片文件**，彻底告别“另存为”对话框！

---

### 🎯 3. 智能截屏 & 滚轮层级穿透检测
* **滚轮向上/向下穿透探测父子层级**：
  * 鼠标悬停在复杂网页或 IDE 上，**向上滚轮**即可顺滑扩展选中整个父容器/窗口；**向下滚轮**深入精准选中内层小按钮，彻底告别手抖对不准！
* **像素级取色器放大镜**：
  * 十字光标自带高倍网格放大镜与实时坐标，按 `C` 直接复制 HEX/RGB 颜色代码，按 `Shift` 快速切换色彩空间。
* **多元截屏一应俱全**：
  * 支持自定义矩形、活动窗口捕捉、延时截屏，更配备**平滑长截图 (滚动截屏)** 与 **GIF 高清动态录屏**。
* **二维码 / 条码自动识别**：
  * 画面中出现二维码时，底层引擎毫秒级扫描定位，信息触手可及。

---

### ✏️ 4. 专业教程标注箱：指引制作行云流水
* **步骤序号自动递增标注 (① ② ③)**：
  * 制作使用教程、操作手册与 Bug 报告的绝对利器！点击一次自动放置编号圈并自增序号，逻辑条理一目了然。
* **防丢失高对比度文字标注**：
  * 文字标注内置轻量高对比圆角微底衬，不论在全白页面还是复杂彩色壁纸上，字迹都清晰锐利，永不被底图吞没。
* **全套标注与打码工具**：
  * 矩形、椭圆、自由画笔、荧光记号笔、直线、折线、双向箭头、个性图章。
  * 内置**马赛克**与**高斯模糊**，轻松隐去敏感密码、人脸与数据。
* **顺畅撤销与删除**：
  * 标注画错无需全部推翻，直接按 `Delete` 或 `Backspace` 单步撤销上一图层。

---

### 🔌 5. 独家原生 MCP 协议支持 (AI 时代的 Agent 眼睛)
Pixora 是业内率先原生实现 **Model Context Protocol (MCP)** 的截图标注工具：
* 可直接作为标准工具服务，接入 **Cursor**、**Claude Desktop**、**Windsurf** 等前沿 AI 开发环境。
* 让你的 AI Agent 拥有“视觉眼睛”：AI 可主动发起截屏、查看当前窗口 UI、调用 OCR 分析、操作贴图，实现真正的全自动桌面级 Agent 协同！

---

### 🗄 6. 本地截图历史库与隐私保障
* **轻量本地 SQLite 存储**：每一次截图自动本地归档，无需担心误关丢失灵感，完全离线运行，绝不上报用户图片。
* **瀑布流检索与二次创作**：支持时间轴浏览、大图预览、二次标注与重新钉在桌面。

## ⌨️ 高频快捷键速查 (Shortcuts)

| 场景 | 默认按键 | 功能说明 |
|:---|:---:|:---|
| **全局快速唤起** | `F1` | 呼出快捷键帮助卡片 |
| | `F7` | 将剪贴板内容（图文/文件）一键贴在桌面 |
| | `Ctrl + Alt + H` | 打开本地截图历史管理器 |
| **截屏选区时** | `滚轮向上 / 向下` | **穿透扩大/缩小选中父级或子级 UI 元素** |
| | `C` | 复制当前十字光标处的像素色值 (HEX / RGB) |
| | `Shift` | 切换色值格式 (HEX ↔ RGB) |
| | `Alt` | 切换放大镜与色值拾取器状态 |
| | `Delete` / `Backspace` | 单步撤销/删除上一条绘制的标注 |
| | `Ctrl + Z` / `Ctrl + Y` | 撤销 / 重做标注图层 |
| | `Esc` | 退出截图或取消当前绘制 |
| **桌面贴图窗口** | `鼠标滚轮` | 10% ~ 500% 平滑缩放贴图 |
| | `5` | **切换黑白/灰度模式** (消除色彩干扰) |
| | `I` | **切换夜间反色模式** (白底反转为柔和黑底) |
| | `R` | 顺时针旋转 90 度 |
| | `F` / `Shift + F` | 水平镜像翻转 / 垂直翻转 |
| | `F9` | **开启/关闭鼠标穿透模式** (点击完全穿透至下层) |
| | `双击贴图` | 复制图片并关闭该贴图窗口 |
| | `鼠标右键` | 弹出贴图操作菜单（另存为、复制、反色、穿透） |

*(所有全局快捷键均可在「设置」面板中自由自定义绑定)*
